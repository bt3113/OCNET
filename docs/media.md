# Media provenance

`public/media/desert.webp` is original AI-generated background artwork created for Oracnet with the built-in image-generation tool, then compressed to WebP. It is not a location claim, supplier image, or product screenshot.

Prompt: photorealistic wide desert landscape in soft morning light; pale ivory, honey, champagne and tan; detailed dunes and limestone along the lower edge; light negative space on the upper left for UI text; no words, logos, products, people, watermark or interface.

`dunes.svg`, `product.svg`, `workspace.svg`, and the favicon are original code-authored illustrations. Product/gallery content is labelled illustrative. Directory lettermarks are illustrative identifiers rather than copied logos. Google Sans Flex is distributed with its SIL Open Font License in `public/fonts/OFL.txt`.

Provider media supports PNG/JPEG/WebP upload, HTTPS screenshot/document links, and allowlisted YouTube/Vimeo embeds that load only after an explicit click. The embed validator rejects arbitrary domains and executable URL schemes. Supabase image upload targets a private bucket; signed URL renewal and public moderation/publishing should be completed before production media delivery.
